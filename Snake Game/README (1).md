
# 🐍 Snake Game with Turtle Graphics

A classic snake game built using Python's `turtle` module. Control the snake, eat the food, and try to get the highest score. The game ends if the snake hits a wall or collides with itself.

---

## 🎮 How to Play

- Use the following keys to control the snake:
  - **W** - Move Up
  - **S** - Move Down
  - **A** - Move Left
  - **D** - Move Right
- The snake grows longer each time it eats food.
- The game ends if the snake hits a wall or itself.

## ▶️ Getting Started

### Requirements

- Python 3.x
- No external packages required (uses built-in `turtle` and `random` modules)

### Run the Game

```bash
python main.py
```

---

## 🧠 Features

- Dynamic snake movement
- Self-collision detection
- Wall collision detection
- Score tracking with a live scoreboard
- Game Over screen
