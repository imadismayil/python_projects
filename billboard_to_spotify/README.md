# Billboard to Spotify 🎧

This project scrapes Billboard's Hot 100 chart and creates a Spotify playlist from it using Spotipy.

## Usage
- Add your Spotify credentials to a `.env` file
- Run the script with a date (YYYY-MM-DD)
- Auth and enjoy the playlist on your Spotify!

## Setup
- pip install -r requirements.txt
- python main.py


## 🏁 How to Run It
In your terminal:
```bash  
cd billboard_to_spotify  
pip install -r requirements.txt  
python main.py
