# 🐢 Turtle Race Game

This is a simple Python project using the `turtle` graphics module where multiple colored turtles race across the screen. The user bets on a color, and the game announces whether the user won or lost based on the outcome of the race.

## 🎮 How to Play

1. When you run the program, a window opens with six turtles of different colors.
2. A popup appears asking:  
   _"Which turtle would win the race? Enter your color"_
3. Type one of these colors:
   - `red`
   - `yellow`
   - `purple`
   - `chocolate4`
   - `bisque3`
   - `DarkGrey`
4. The race starts. Each turtle moves forward randomly.
5. When one turtle reaches the end, the program announces:
   - If you guessed right: `You Win!`
   - If not: `You Lose!`
   - It also shows: `The winning color is: <color>`

## 🧠 Concepts Used

- `turtle` module for simple graphics
- `random` module for randomized movement
- Loops and conditional statements
- User input handling

## 📝 Sample Output

text
You Lose!
The winning color is:  chocolate4
## 🚀 How to Run
Make sure you have Python 3 installed.

Save the script in a .py file, e.g., turtle_race.py

Run it using:
python turtle_race.py
